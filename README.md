# Saudagar Invest

Website dashboard saham sederhana berbasis HTML, CSS, dan JavaScript.

## Isi Repository

- `index.html` — halaman utama website
- `README.md` — dokumentasi repository
- `.gitignore` — file yang diabaikan Git

## Menjalankan di Komputer

Buka `index.html` langsung di browser, atau gunakan ekstensi **Live Server** di Visual Studio Code.

## Publikasi dengan GitHub Pages

1. Upload seluruh isi folder ini ke repository GitHub.
2. Buka **Settings** → **Pages**.
3. Pada **Source**, pilih **Deploy from a branch**.
4. Pilih branch `main`.
5. Pilih folder `/(root)`.
6. Klik **Save**.

Website akan tersedia dalam format:

`https://USERNAME.github.io/NAMA-REPOSITORY/`

## Catatan

Data saham di website ini hanya simulasi dan bukan data Bursa Efek Indonesia secara real-time.
